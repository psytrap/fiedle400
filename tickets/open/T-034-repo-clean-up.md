## Description & Context

No clean-up ticket existed (checked `tickets/open/`, `tickets/done/` and
`DONE.md` on 2026-10-20). This one records what an inspection of the synced
repo found, split by who can act on it. It is a checklist for a later pass,
not an instruction to delete anything now.

### A. Tracked in git (can be done by a normal patch)

- **Duplicate `trace-response.md` in the repo root.** It is byte-identical to
  `handoff/trace-response.md`; the only reference to it is
  `handoff/fix-order-approved.md`, which names it as `handoff/trace-response.md`.
  Remove the root copy (`git rm`).
- **`fiedle400.bat` wording.** The comment line says "Pulsox PO-400 CLI". The
  device name stays PO-400 in user text (AGENTS.md), so only check that the
  launcher still works (`python -m fiedle400`) and that the wording matches the
  README; probably nothing to change.
- **Decision for psytrap: keep `handoff/`?** It is frozen and still cited by
  filename from several docs. Keeping it is the safe default; archiving or
  deleting it would mean rewriting those citations. Record the decision here;
  do not move it without one.
- **Look for other root-level strays** with `git ls-files` on the device
  (files not referenced by any doc, test or script) before the pass starts.

### B. Local only (ignored by git, so no patch can touch them)

These are on the device or in the cloud mirror, not in the repo. `.gitignore`
already covers all of them (no gap found), so this is only about disk space and
confusion when looking around:

- Applied patch files in the repo root (`*.patch`; `scripts/sync_patch.py apply`
  keeps a copy of each). Safe to delete once applied and committed.
- `archive/` (about 284 MB: SpO2.exe brute-force material, pcaps). Keep, but
  confirm a backup exists outside the working folder.
- `build/` and `dist/` (PyInstaller output), `po400.egg-info/` and
  `fiedle400.egg-info/` (stale, the second is regenerated by `pip install -e`),
  `__pycache__/` folders.
- `po400.zip` and two `po400_2026-09-30T195453_2026-09-30T195827*.spo2` files in
  the repo root (old recordings; move to a `recordings/` folder outside the repo
  if they are still wanted).
- `output/` scratch (agent workfiles, by the workspace rule).

- Which of the local files in B psytrap still wants.

  local agent) to do locally; the cloud's part is section A, as a patch.
